Panduan Resmi Penggunaan System

Tutorial & Petunjuk Operasional Aplikasi

Panduan langkah demi langkah pengelolaan SMS PAUD - Terpadu Manajemen & Kepegawaian. Pelajari cara menginput data siswa, mencetak PDF, mengelola presensi, SDIDTK, slip gaji, keuangan, tabungan, PPDB, dan penerbitan surat kepegawaian.

1. Buku Induk Murid

Pendataan & Registrasi Siswa

  1. Klik menu Buku Induk Murid di sidebar atau tombol pintasan dashboard.
  2. Tekan tombol + Tambah Buku Induk Siswa untuk membuka formulir.
  3. Isi NIS, NISN, Tahun Ajaran, Nama, TTL, Kelompok, dan Data Ortu.
  4. Tekan Cetak PDF di kolom aksi untuk mengunduh biodata individual siswa atau Cetak Buku Induk PDF untuk laporan master.

2. Kepegawaian Guru & Staf

Master Pendidik & Tendik

  1. Buka menu Data Guru & Staf.
  2. Klik + Input Buku Induk Pegawai dan lengkapi NIP, NIK, Status GTY/GTT, No. SK, TMT, dan foto.
  3. Foto profil dapat diunggah langsung dari perangkat atau melalui link URL.
  4. Gunakan tombol Cetak PDF untuk mencetak lembar biodata resmi pendidik.

3. Presensi & Absensi

Log Kehadiran Siswa & Guru

  1. Buka menu Presensi Harian.
  2. Gunakan tombol + Input Absensi Siswa atau + Input Presensi Guru.
  3. Tentukan jam masuk, jam pulang, status (Hadir, Izin, Sakit, Alpha / Tepat Waktu, Terlambat).
  4. Pilih sub-tab Rekap Absensi lalu klik tombol View dan Cetak PDF untuk rekap absensi per individu.

4. SDIDTK Tumbuh Kembang

Pengukuran BB, TB, & LK

  1. Buka menu SDIDTK Tumbuh Kembang.
  2. Klik + Pengukuran SDIDTK Baru. Pilih nama murid, masukkan Berat Badan (kg), Tinggi Badan (cm), dan Lingkar Kepala (cm).
  3. Pilih status motorik (Sesuai Usia, Meragukan, Penyimpangan).
  4. Klik tombol Cetak Laporan SDIDTK PDF untuk mengunduh rekap master.

5. Payroll & Slip Gaji

Penggajian, PPh 21, & THP

  1. Buka menu Slip Gaji Pegawai.
  2. Klik + Generasi Slip Gaji Pegawai, pilih guru/staf dan bulan periode penggajian.
  3. Isi gaji pokok, tunjangan jabatan, insentif, BPJS, PPh 21, dan kasbon. Sistem otomatis menghitung Take Home Pay (THP).
  4. Klik Cetak PDF di kolom aksi untuk mengunduh Slip Gaji PDF individual yang siap dicetak.

6. Keuangan & SPP

SPP, Beasiswa, & Kwitansi

  1. Buka menu Keuangan & Pembayaran.
  2. Klik + Transaksi Keuangan / SPP. Pilih siswa dan kategori biaya (SPP, Sarpras, Outing Class, dsb).
  3. Jika penerima beasiswa, pilih jenis beasiswa untuk pemotongan biaya otomatis.
  4. Klik tombol Cetak Kwitansi di tabel transaksi untuk mencetak kwitansi resmi PDF A5.

7. Tabungan Siswa

Mutasi Setor, Tarik, & Saldo

  1. Buka menu Tabungan Siswa.
  2. Klik + Setor / Tarik Tabungan. Sistem menampilkan saldo berjalan siswa terpilih.
  3. Pilih jenis transaksi (Setoran / Penarikan) dan nominal.
  4. Gunakan tombol Cetak Buku Tabungan pada sub-tab Rekap untuk mengunduh buku tabungan lengkap siswa.

8. PPDB Online Baru

Penerimaan Siswa Baru

  1. Buka menu PPDB Online Baru.
  2. Klik + Form Pendaftaran PPDB untuk menginput calon peserta didik baru.
  3. Pilih Gelombang (1, 2, 3), Kelompok Usia, Data Orang Tua, dan Dokumen Berkas.
  4. Cetak bukti formulir pendaftaran melalui tombol Cetak PDF di kolom aksi.

9. Surat Kepegawaian

Penerbitan Surat Resmi

  1. Buka menu Surat Kepegawaian.
  2. Klik + Buat Surat Baru. Pilih jenis surat (Keterangan Kerja, Surat Tugas, Izin Cuti, Teguran, dsb).
  3. Sistem membuat Nomor Surat resmi secara otomatis. Isikan deskripsi dan penandatangan surat.
  4. Tekan Cetak Surat PDF di tabel untuk mengunduh dokumen surat lengkap bermeterai/kop lembaga.

Pertanyaan Umum & Bantuan Operasional (FAQ)

Bagaimana jika data tersimpan tidak muncul?

Seluruh data disimpan secara otomatis pada memori lokal peramban (browser LocalStorage). Pastikan Anda tidak menghapus history browser secara paksa.

Apakah dokumen PDF dapat di-print langsung?

Ya. Seluruh tombol PDF (Biodata, Kwitansi, Slip Gaji, Surat, & Buku Tabungan) akan langsung diunduh dalam format PDF resmi dan siap dicetak menggunakan printer standar (A4 / A5).
